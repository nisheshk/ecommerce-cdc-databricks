# Data Engineering Standards: Workspace Instructions

These rules apply to every Genie Code response in this workspace. They cover Unity Catalog tables and Lakeflow Spark Declarative Pipelines (SDP).

## Table documentation

- Every table MUST have a `COMMENT` describing its purpose.
- Every table MUST have `TBLPROPERTIES` with at least `quality` (bronze, silver or gold) and `domain`. Do not set `owner` (reserved property).
- Tables with personal data MUST also set `"contains_pii" = "true"` and `"pii_columns" = "<column_list>"`.
- PII columns MUST carry an inline comment with the risk level, e.g. `-- [PII: EMAIL - HIGH]`.
- Primary keys, derived columns and PII columns MUST have column descriptions (`ALTER TABLE ... ALTER COLUMN ... COMMENT`).
- Unity Catalog tags `quality`, `domain`, `pii` and `data_classification` MUST be applied to every table.

## Naming

- The medallion layer is the schema: `<catalog>.bronze`, `<catalog>.silver`, `<catalog>.gold`, plus `<catalog>.ops` for quarantine and test results.
- Table and column names MUST be lowercase_snake_case. No PascalCase, UPPERCASE, kebab-case or camelCase.
- CDC targets end in their SCD type: `customers_scd1`, `customers_scd2`.

## Audit columns

- Every table MUST end with `audit_timestamp` and `source_system`, as the LAST columns.
- Bronze also keeps the file metadata `_ingest_ts` and `_source_file`.

## Pipeline language

- Define pipeline tables in SQL (`CREATE OR REFRESH STREAMING TABLE`, `CREATE OR REFRESH MATERIALIZED VIEW`, `AUTO CDC`).
- Python is allowed only as a thin wrapper around tested functions in `src/ecommerce/transforms/`. Put no business logic in a pipeline decorator.

## CDC

- Apply changes with `AUTO CDC`, `SEQUENCE BY lsn` (never `ts_ms`), and `APPLY AS DELETE WHEN op = 'd'`.
- Reject null keys and unknown `op` values with expectations before `AUTO CDC`, and route rejects to `ops` quarantine tables.

## Skills

Skills live in `/Workspace/.assistant/skills/<skill-name>/`. Genie Code loads one when a request matches its description; `@<skill-name>` forces it. When creating or modifying tables:

- `@de-table-governance`: comments, TBLPROPERTIES, column descriptions, UC tags. Apply first, to every table.
- `@de-declarative-pipelines`: bronze/silver/gold patterns, expectations, AUTO CDC, watermarks and joins. Every pipeline table.
- `@de-pii-management`: PII detection, labels, column masks, row filters. Any table with personal data.
- `@de-testing`: unit tests for transforms, integration tests for pipelines. Any new or changed transform.
- `@de-sentiment-analysis`: AI functions (sentiment, topic, extraction) on free-form text such as product reviews. Compose with the skills above.
- `@de-bundles`: `databricks.yml`, targets and resources. Any deployment change.
