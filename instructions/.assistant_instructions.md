# E-commerce CDC Lab: User Instructions

When creating or modifying pipeline tables, follow the workspace instructions and the skills below.

## Pipeline routing

| Pipeline | Catalog | Standards |
| --- | --- | --- |
| `ecom_pipeline` | `ecom_lab` | Workspace standards + the skills below |
| `<your-other-pipeline>` | `<catalog>` | Workspace standards |

The lab spec is `src/ecommerce/SPEC.md` in the bundle. Use its scenario IDs (`CDC-02`, `LA-03`, ...) when asked to build or test a scenario.

## Skills

Skills are in `/Workspace/.assistant/skills/` (team) or `/Users/<your email>/.assistant/skills/` (yours). For every table:

- Always apply `@de-table-governance` first, then `@de-declarative-pipelines`.
- If the table holds customer or personal data (`customers`, `clicks.ip`), also apply `@de-pii-management`.
- If the table derives sentiment, topics or entities from text with AI functions, also apply `@de-sentiment-analysis`.
- If you add or change a function in `src/ecommerce/transforms/`, also apply `@de-testing`.

## Quick reminder

- Audit columns: `audit_timestamp`, `source_system` as the LAST columns.
- Every table: `COMMENT`, and `TBLPROPERTIES` with `quality` and `domain = 'ecommerce'`. Do not set `owner`.
- Column descriptions for primary keys, derived columns and PII columns.
- Bronze: Auto Loader from `/Volumes/ecom_lab/landing/raw/`, keep the raw envelope plus `_ingest_ts` and `_source_file`, `CLUSTER BY AUTO`.
- Silver: `CONSTRAINT ... EXPECT` before `AUTO CDC`, `SEQUENCE BY lsn`, rejects to `ecom_lab.ops`.
- Gold: `ROUND()` for money; no PII columns; join same-pipeline tables by name (no `LIVE.` prefix).
- PII: mask email, phone and address with the `ecom_lab.ops` functions; use `sha2(email, 256)` as `email_hash` for joins.
